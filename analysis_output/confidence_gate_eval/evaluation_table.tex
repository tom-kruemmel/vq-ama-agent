% The default prompt passes the user query unmodified to retrieval, producing
% identical results across all models (F1_macro = 0.741).  Hyde, which generates
% a hypothetical answer document for retrieval, is the strongest prompt on average
% (mean F1_macro = 0.749): it broadly lifts cross-encoder scores, recovering
% borderline false negatives such as the Drittanbieter-Software question
% (avg_top3 shifts from -2.20 to -1.39) without disturbing true negatives for
% GPT-OSS and Qwen3.  Decompose, which breaks the query into sub-questions, is
% the most polarising prompt (spread = 0.073): it produces the single best result
% overall when paired with Nova Pro (0.770), because its sub-questions dilute the
% spurious Redux~EN match (avg_top3: -1.73 -> -2.24, flipping FP to TN), yet it
% is the worst prompt for Mistral (0.697) and Nova Lite (0.719), where the
% narrower sub-queries push borderline answerable questions such as Call-Prep
% benefits and Audits~EN below the -2.0 threshold (TP -> FN).  Diverse,
% which retrieves for multiple paraphrases, never achieves the best result for
% any model (mean F1_macro = 0.725); its broader retrieval dilutes the top-3
% average without recovering any false negatives, and it degrades Call-Prep
% benefits~DE for smaller models (avg_top3: -1.74 -> -2.14).
